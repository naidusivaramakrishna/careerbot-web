# CareerBot Browser Extension

## Setup
1. Open Chrome → chrome://extensions
2. Enable Developer mode (top right)
3. Click "Load unpacked"
4. Select this folder: careerbot-extension/
5. Done! The CareerBot icon will appear in your toolbar.

## Usage
1. Visit LinkedIn, Naukri, or Indeed job page
2. A purple banner appears at bottom-right: "Tailor Resume"
3. Click it → Extension popup opens with JD pre-filled
4. Select your resume → Click "Tailor & Open Portal"
5. CareerBot portal opens with match analysis ready

## Requirements
- Backend running at localhost:8000
- Frontend running at localhost:3000
- Must be logged in at localhost:3000 first

SECTION 1 -- CONTEXT & PRODUCT GOAL
=====================================

The mock test feature is a multi-section timed online assessment tool used by job seekers to
practice aptitude, reasoning, and technical skills before company placement tests.

USER JOURNEY:
  Landing -> Loading -> Section Intro -> [Section Testing x N] -> Results Summary -> Submit -> Results Page

FIVE PHASES IN [id]/page.tsx:

  Phase              | Trigger                    | Purpose
  -------------------|----------------------------|-----------------------------
  loading            | Page mount                 | Session init / question gen
  section_intro      | After each section loads   | Rules + start card
  section_testing    | After "Start Now" clicked  | Live timed test
  results_summary    | After all sections done    | Pre-submit review
  submitting         | After final submit click   | Score calculation wait

DESIGN SYSTEM:
  Primary:    #0f2044 (deep navy) -> #2557a7 (mid navy) gradient
  Success:    emerald-500
  Warning:    amber-400
  Error:      red-500
  Background: slate-50 / #f0f4f8
  Font scale: text-xs -> text-5xl, weights font-medium -> font-black

SECTION 3 -- DESIGN ISSUES (Severity: MEDIUM)
===============================================

DES-01 · Inconsistent color system -- too many one-off colors
  Files:   Both
  Problem: #7eb3f8, #0a1628, #1a3560 are used inline without being part of the
           defined design token system. This causes visual inconsistency at scale.
  Fix:     Define all colors in tailwind.config.ts as named tokens:
             colors: {
               navy: { 950: '#0a1628', 900: '#0f2044', 700: '#1a3560',
                       500: '#2557a7', 300: '#7eb3f8' }
             }
           Then replace all hardcoded hex with text-navy-900, bg-navy-500, etc.

DES-02 · Typography scale is inconsistent
  Files:   Both
  Problem: Mix of text-[10px], text-xs, text-sm, text-base, text-lg, text-xl,
           text-2xl, text-3xl, text-4xl, text-5xl -- 10 different sizes in 2 files.
           A premium product uses max 5-6 type levels.
  Fix:     Standardize to:

    Token    | Size                   | Use
    ---------|------------------------|------------------
    display  | text-4xl font-black    | Hero headings
    heading  | text-2xl font-bold     | Section titles
    title    | text-lg font-semibold  | Card titles
    body     | text-base font-medium  | Body text
    caption  | text-sm                | Labels, hints
    micro    | text-xs font-semibold  | Badges, tags

DES-03 · Section testing question area padding too large on mobile
  File:    [id]/page.tsx · Line 1209
  Problem: p-8 (32px) on a mobile screen wastes 64px horizontally.
  Fix:     Change: className="flex-1 overflow-y-auto p-8"

DES-04 · Answer options have no minimum tap target size on mobile
  File:    [id]/page.tsx · Lines 1246-1283
  Problem: Options use p-4 padding but no explicit min-h. On small screens

DES-05 · Results page hero SVG circle does not scale on mobile

DES-06 · Question palette grid breaks for >25 questions

DES-07 · Empty loading skeleton -- all phases show plain spinners

SECTION 5 -- PERFORMANCE ISSUES
=================================

PERF-01 · Five uncoordinated API calls on results page mount
  File:    results/[id]/page.tsx · Lines 56-148
  Problem: 5 separate useEffect hooks fire independently, causing 5 network
           waterfalls instead of a coordinated parallel fetch.
  Fix:     Consolidate with Promise.allSettled:
             useEffect(() => {
               Promise.allSettled([
                 getWeakAreasAnalytics(),
                 getLeaderboard(),
                 getMockTestHistory(),
                 getProgressAnalytics(),
               ]).then(([weak, lb, hist, prog]) => {
                 if (weak.status === 'fulfilled') setWeakAreas(weak.value);
                 if (lb.status === 'fulfilled')   setLeaderboard(lb.value);
                 if (hist.status === 'fulfilled') setHistory(hist.value);
                 if (prog.status === 'fulfilled') setProgressAnalytics(prog.value);
               });
             }, []);

PERF-02 · Framer Motion imported in full on test page
  Files:   Both
  Problem: framer-motion full bundle (~35kb gzip) loaded for simple animations.
  Fix:     Use LazyMotion for production:
             import { LazyMotion, domAnimation, m } from 'framer-motion';
             Replace <motion.div> with <m.div> inside <LazyMotion features={domAnimation}>

PERF-03 · sectionColors array with gradient strings concatenated every render
  File:    [id]/page.tsx · Lines 53-59
  Problem: NAVY_BTN and NAVY_PROGRESS constants are long className strings
           concatenated on every render cycle.
  Fix:     Move to CSS modules or Tailwind @apply for reuse without string concatenation.

PERF-04 · Question transitions re-mount entire question component
  File:    [id]/page.tsx · Line 1207
  Problem: key={currentQ} causes full unmount/remount on every question navigation,
           resetting all DOM state. Use layout animations instead.
  Fix:     Replace key={currentQ} with:
             <motion.div layout animate={{ opacity: 1, x: 0 }} initial={{ opacity: 0, x: 12 }}>

PERF-05 · handleSectionSubmit and finalSubmit not wrapped in useCallback
  File:    [id]/page.tsx
  Problem: Functions recreated on every render, causing child re-renders.
  Fix:     const handleSectionSubmit = useCallback(async () => { ... }, [sessionId, questions, ...deps]);
